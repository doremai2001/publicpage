# FIXES — 子宮內膜癌專題中文正文修訂指令（編輯裁決後）

修訂 agent 依組別修自己組的檔案。**兩份查核報告 `review-safety.md`、`review-voice.md` 裡屬於你這組
檔案的條目全部要處理**，除了下面「編輯否決」的幾條。報告每條都附原句與替換句；替換句是建議，
你可以寫得更好，但**問題必須消失**。

## 改完必須維持的不變式

- 只用允許的標籤；內文 `[n]` 依首次出現順序連號；參考資料條目數與 href 逐條對應；
  全篇一個 `<hr>` 一個 `<h3>`；檔尾 `<p></p>`。
- 若某項修改刪掉了某個引用的最後一次出現，**把該條參考資料一併刪除並全部重新編號**（內文與清單都要）。
- 若需要新增引用，**只能從你這組 brief 的 PASS 來源拿**，書目照 brief 逐字抄。
- **不要動任何一條既有參考資料的書目資料**（作者、年份、期刊、卷期頁、DOI）——它們已用程式對過
  Europe PMC。`verify_refs.py` 報的 NOT FOUND／title mismatch **是工具誤報**，已知形狀：
  DOI 內含半形括號（`S1470-2045(25)00167-6`）被正則截斷、頁碼縮寫（`e631-e638` 對 `e631-8`）、
  無卷期頁的書目（Cochrane、`Gynecol Oncol 213, 25–32`）、線上 title 含 `<sub>`／`<sup>`／`<i>`、
  URL 尾巴 `/full` 被誤當 DOI。**不要「修正」書目。**
- **利益揭露段（B1、B2、B3、B4）一個字都不能動。**
- **h4 標題若有變動一定要回報（列新舊對照）**——繪圖 manifest 的 `placement.after_h4` 對的是 h4 全文，
  圖還沒開始畫，等你們回報之後才畫。
- 改完重跑：
  `python3 /home/claude/endo/check_article_html.py /home/claude/endo/body/<你的檔>.html --leads <leads.json> --max <見下>`
