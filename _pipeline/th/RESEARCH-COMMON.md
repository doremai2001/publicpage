# 甲狀腺癌專題　查證共同規範（五組共用）

## 零、這一份要先讀

你是五個平行查證組之一。**你的 brief 第一節必須是〈⚠ 與 SPEC 假設不同形狀的事〉**：把你查到的、與 `SPEC.md` 寫的不一樣的事情逐條列出來（包含「SPEC 說要查的東西根本不存在」「SPEC 把 A 當成 B」「這個指引已經改版」）。編輯會拿五組的這一節做跨組裁決，寫進 SPEC §九，覆寫 SPEC 前面所有章節。**不要自己去「順手修正」SPEC，只要回報。**

## 一、這個病的四條分界線——任何一個數字都必須標明它落在哪一邊

甲狀腺癌最容易出事的地方是**數字跨線**。以下四條線，每一個你寫進 brief 的數字都必須同時帶著它的標籤，沒有標籤的數字一律標 FAIL：

1. **組織型**：乳突癌／濾泡癌／嗜酸性細胞癌（Hürthle／oncocytic）／髓質癌／未分化癌。分化型（乳突＋濾泡＋嗜酸性）的數字不可用在髓質癌或未分化癌上，反之亦然。
2. **「期別」與「復發風險組」是兩套系統**：AJCC／TNM 分期預測的是**死亡**；ATA 三級復發風險分層預測的是**結構性復發**。兩者的 low/intermediate/high 不可互相翻譯，也不可混在同一句話裡。
3. **年齡切點與 AJCC 版本**：第八版（2018 年起）的切點是 **55 歲**，第七版是 **45 歲**。2018 年以前發表的世代多半用第七版。**每一個期別數字都必須標明它用的是第幾版。** 只寫「第 II 期」而不說版本的數字，標 FAIL。
4. **終點**：disease-specific survival（疾病特異性存活）／overall survival／structural recurrence（結構性復發）／biochemical incomplete response（生化性反應不完全）／excellent response。這四個不是同一件事，尤其分化型甲狀腺癌的 OS 受其他死因稀釋得很嚴重。

另外三個必帶標籤：

- **腫瘤大小**：≤1 公分（微小乳突癌 PTMC）自成一套文獻，它的數字不可以外推到 1–4 公分。
- **做過什麼手術**：全甲狀腺切除與單葉切除之後，**甲狀腺球蛋白（Tg）的判讀閾值完全不同**；任何 Tg 數字必須標明手術範圍以及有沒有做過放射碘。
- **有沒有做放射碘**：RAI-naive 與 RAI-treated 世代的追蹤數字不可互相引用。

## 二、來源路徑

- 文獻：**Europe PMC REST**
  `https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=EXT_ID:<PMID>&resultType=core&format=json`
  OA 全文：`https://www.ebi.ac.uk/europepmc/webservices/rest/<PMCID>/fullTextXML`
  （PubMed 網頁會 CAPTCHA；本 session 的 PubMed MCP 不保證可用，以 Europe PMC 為準）
- 試驗狀態：`https://clinicaltrials.gov/api/v2/studies/<NCT>`
- **NCCN 一律不引用**（自動抓取回 403，連版本字串都取不到）。改用 ATA／ESMO／ESTRO／ASCO／ETA（European Thyroid Association）／BTA／JAES-JSTS 與 WHO 分類。
- 台灣端：健保支付標準與藥品給付規定用**全文檔搜尋**；`hpa.gov.tw` 常 TLS 失敗，改 `mohw.gov.tw` 對應頁；法規用 `law.moj.gov.tw`。藥證查食藥署。

## 三、鐵則

- 每一條來源標 **PASS** 或 **FAIL**，並寫下查證路徑（你實際打了什麼網址、看到什麼字）。**寫作組只能引用 PASS 的來源。**
- **不得憑記憶寫 PMID 或 DOI**；URL 逐字元複製。
- **中文大寫金額一律逐字回抄原始字元**（曾把「壹拾貳萬元」讀成 120 萬）。
- **健保全文搜尋零筆 ＝ 寫成「查無列項，要問醫務課或個管師」**，永遠不推論有或沒有給付。
- **媒體報價一律不引用。**
- 指引的**建議強度與證據等級要一起抄**，並抄原句（英文原文逐字）。
- 參考連結**不要用 `.pdf` 或 `/full` 結尾的網址**（DOI 會被正規式截斷）。
- 標題**逐字抄 Europe PMC 回傳的 title**，不要自己縮短。
- **勝算比／風險比的信賴區間是幾何對稱，迴歸係數是算術對稱。** 遇到兩者不合的，回報為「來源自己標錯」，不要照抄。
