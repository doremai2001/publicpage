# 寫作規格（五個寫作組共用）——版式、文風、機械查核

## 一、你要產出什麼

每一篇兩個東西：

1. `/home/claude/th/body/<slug>.html` —— **正文 fragment**（不是完整網頁，沒有 `<html>`／`<head>`／`<h1>`）
2. 你那一組的 `/home/claude/th/meta/<組別>.json` 裡的一筆 —— `title`／`dek`／`lead`／`note` 四個欄位

## 二、正文 fragment 的精確版式

```html
<p>開場第一段。</p>

<p>開場第二段：這一篇要解決什麼、以及哪些東西不在這一篇（用〈標題〉指向姊妹篇）。</p>

<h4>小節標題</h4>

<p>內文……引用長這樣<a href="https://doi.org/10.xxxx/yyy" target="_blank" rel="noopener"><sup class="cit">[1]</sup></a>。</p>

<h4>下一個小節標題</h4>

<p>……</p>

<hr><h3>參考資料</h3>
<ol>
<li><p>Surname, A.B., Surname, C.D., et al. (2025). <a href="https://doi.org/10.xxxx/yyy" target="_blank" rel="noopener">逐字抄來的論文標題</a>. Journal Name, 35(8), 841–985. DOI: 10.xxxx/yyy</p></li>
<li><p>衛生福利部中央健康保險署。<a href="https://…" target="_blank" rel="noopener">全民健康保險醫療服務給付項目及支付標準</a>（開放資料原始檔，2026-09-14 版）。</p></li>
</ol>
<p></p>
```

鐵律：

- **開頭沒有 `<h1>`**，沒有標題；直接兩段 `<p>` 開場，然後才有第一個 `<h4>`
- **引用編號依第一次出現的順序從 1 編到 N**，`<ol>` 的順序必須完全一致；同一個來源重複引用時沿用同一個編號與同一個 URL
- **每個 `<sup class="cit">` 都必須包在 `<a>` 裡**，`target="_blank" rel="noopener"` 逐字照抄
- 參考連結**不得以 `.pdf` 或 `/full` 結尾**；論文標題**逐字抄 Europe PMC 回傳的字串**，不要自己縮短或翻譯
- 結尾固定是 `</ol>` 之後一個空的 `<p></p>`
- **不要用表格**（`<table>` 全站不用），要比較就寫成段落或條列句
- `<ul>`／`<li>` 可以用，但一篇最多兩處；這個站的文體是散文不是清單
- **正文裡不放圖**——圖由建站腳本插入，你不要寫任何 `<figure>`

## 三、文風（這是一位主治醫師在門診講話的樣子）

- **第一人稱是「我」**，講的是我怎麼看、我會問什麼、我不往哪一邊推論。不要寫「本文將介紹」。
- 句子要短。一個句子講一件事。
- **不要用「首先／其次／最後」「總而言之」「值得注意的是」「綜上所述」這類公文詞。**
- 專有名詞第一次出現時用一句白話解釋，之後直接用。統計名詞（勝算比、風險比、信賴區間、非劣性、C 指數）第一次出現一定要翻成白話，**而且中英文版都要有**。
- **每一個數字後面都要帶它的族群標籤**（見 RESEARCH-COMMON.md §一 的四條線）。沒有標籤的數字不要寫。
- 每一篇結尾最後一段是「所以下次門診你可以問什麼」的具體句子——不是鼓勵，是可以照著念的問句。
- 指向姊妹篇用〈書名號〉，**加不加連結看 SPEC §九 修正 54**；同一段不重複同一個指向。

## 四、機械門檻（查核會量，超標就退回）

- **`<strong>` 密度 ≤ 7 個／1,000 個漢字**。這個站已上線的頁面是 0–7.4，超過就是在用粗體代替論證。
- **拉丁字母密度**：一篇 2,000 字的文章裡，拉丁字元（含藥名、試驗名、指引英文原句）**不超過 900 個**。不要整段貼英文再翻譯；指引原句只引真正需要逐字的那一句，其餘用中文轉述。
- 字數帶 **1,300–2,500 個漢字**（不含參考資料）。
- `<h4>` 每篇 5–9 個。
- 參考條目 8–20 筆。

## 五、meta 四個欄位

- `title`：≤14 個漢字，**逐字照 SPEC §四 給的標題**，不要自己改
- `dek`：一句，40–55 字，寫這一篇的張力在哪，不是摘要
- `lead`：一句到兩句，60–90 字，站在讀者的誤解上把它翻過來
- `note`（＝頁面上的「醫師的話」）：80–130 字，**寫成可以照著念的門診問句或一個具體動作**，不要寫鼓勵

## 六、你只能引用 PASS 的來源

你那一組的 brief 裡標 PASS 的才能引。標 FAIL 的、或 SPEC §九 明文 barred 的，一律不可以出現，**即使你「知道」那個數字**。查不到的東西就寫「我查不到」，不要補空。
